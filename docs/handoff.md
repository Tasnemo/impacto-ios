## Known Failures / Limitations
- **No real Steam data was used.** All runtime evidence is synthetic.
- Stubbed opcodes parse but do nothing: `00 35/41/43/4B/4C/50/53/58/59`,
  `01 06/07/08/09/0A`, `10 1A/27/37/3F` (logged once as
  `STUB … [SGHD, logged once]`).
- `font.lua` (PS3 64×14 grid), `dialogue.lua` (`DialogueBoxType.Plain`),
  sprite ids, `StartScript = 2` are placeholders; movies are not mounted.
- Save format is not Steam-compatible; FlagWork/ScrWork ranges are CHLCC
  defaults; no save/load menus; tips/CG/BGM unlocks not persisted.
- Engine still segfaults without an audio device (use `ALSOFT_DRIVERS=null`).
- Windows/macOS not built here; DX9 window unchanged.
